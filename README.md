# dsh-markdown-.md-reading-position
让 DSH 右侧栏的 Markdown 文档预览记住每个文件的阅读位置：切换会话、关闭再打开预览、重启客户端后，都会回到上次读到的位置。
#支持0.2.1-rc.2。
安装下载压缩包解压后从dsh插件→添加插件→填入本地解压路径即可，或者直接让大肥鱼帮你装。
